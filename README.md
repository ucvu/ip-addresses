# Настройка WireGuard на роутерах Netcraze

Набор Python-скриптов для установки и обновления WireGuard-подключения на роутере через веб-API RCI. Скрипты формируют списки доменов и IP-подсетей из базы [v2ray-rules-dat](https://github.com/Loyalsoldier/v2ray-rules-dat), создают для них маршруты DNS и позволяют направлять выбранный трафик через VPN или напрямую.

## Возможности

- первичная установка компонента WireGuard и импорт конфигурации `.conf`;
- обновление списков и маршрутов без повторного импорта конфигурации;
- смена `endpoint` у существующего WireGuard-подключения;
- настройка нескольких роутеров за один запуск;
- генерация списков по готовому или пользовательскому пресету;
- поиск доступных категорий в `geosite.dat` и `geoip.dat`.

## Требования

- Python 3.10 или новее;
- пакеты `requests` и `python-dotenv`;
- доступ к веб-интерфейсу роутера;
- WireGuard-конфигурация от VPN-провайдера — для первичной установки.

Установите зависимости:

```bash
python -m pip install requests python-dotenv
```

Создайте `.env` из шаблона:

```bash
cp .env.example .env
```

Для PowerShell:

```powershell
Copy-Item .env.example .env
```

Затем укажите в `.env` данные доступа к роутеру:

```dotenv
ROUTER_USERNAME=admin
ROUTER_PASSWORD=ваш_пароль
```

Файл `.env` загружается из каталога со скриптами и исключён из Git. Не публикуйте его и не добавляйте в репозиторий.

## Быстрый старт

1. Поместите единственный файл WireGuard с расширением `.conf` в каталог со скриптами.
2. Создайте и заполните `.env`, как описано выше.
3. Выберите готовый пресет или создайте свой.
4. Запустите первичную установку:

```bash
python install_wireguard.py --action install --preset preset-services-only.txt --router 192.168.1.1
```

При первом запуске будут скачаны `geosite.dat` и `geoip.dat`. После успешной установки использованный `.conf` удаляется. Чтобы сохранить его, добавьте `--keep-conf`.

> [!CAUTION]
> Действия `install` и `update` удаляют **все** существующие списки и правила в разделе «Маршрутизация → Маршруты DNS», а затем создают их заново. Скрипт также временно отключает все найденные WireGuard-интерфейсы и может изменить приоритет Ethernet-подключения.

## Пресеты

Первая строка задаёт режим маршрутизации:

- `mode: proxy` — выбранные домены и подсети направляются через WireGuard;
- `mode: direct` — выбранные домены и подсети направляются через Ethernet в обход VPN.

Остальные строки содержат источники правил:

```text
mode: proxy

geosite:openai
geosite:youtube
geoip:telegram
domain:example.com
domain:203.0.113.10/32
```

Поддерживаются записи:

- `geosite:name` — домены категории из `geosite.dat`;
- `geoip:name` — IP-подсети категории из `geoip.dat`;
- `domain:value` — ручная запись: домен попадёт в `geosite_domains_*.txt`, а валидный IP или CIDR — в `geoip_ips_*.txt`;
- пустые строки и строки с `#` — игнорируются.

В репозитории есть два примера:

- `preset-services-only.txt` — выбранные сервисы через VPN;
- `preset-ru-direct.txt` — российские ресурсы напрямую.

## Основные команды

Обновить списки и маршруты на уже настроенном роутере:

```bash
python install_wireguard.py --action update --preset preset-services-only.txt --router 192.168.1.1
```

Сменить адрес WireGuard-сервера, не затрагивая списки и маршруты:

```bash
python install_wireguard.py --action endpoint --endpoint vpn.example.com:51820 --router 192.168.1.1
```

Адрес роутера можно передать как локальный IP, доменное имя или полный URL. Для IP скрипт использует HTTP, для доменного имени — HTTPS.

Полезные параметры:

- `--online` — принудительно скачать свежие `geosite.dat` и `geoip.dat`;
- `--generate-off` — использовать уже созданные `geosite_domains_*.txt` и `geoip_ips_*.txt`;
- `--vpn-off` — оставить VPN выключенным после выполнения;
- `--keep-conf` — не удалять `.conf` после первичной установки.

Полная справка:

```bash
python install_wireguard.py --help
```

## Несколько роутеров

Создайте рядом со скриптами файл `routers.txt`, указав по одному адресу на строку:

```text
192.168.1.1
router.example.com
# комментарий
```

Обновите все роутеры:

```bash
python setup_routers.py --preset preset-services-only.txt
```

Смените endpoint на всех роутерах:

```bash
python setup_routers.py --action endpoint --endpoint vpn.example.com:51820
```

Первичная установка через `setup_routers.py` намеренно недоступна. Ошибки на отдельных роутерах не останавливают обработку остальных; их адреса записываются в `update_failed.txt`. Повторный запуск только для них:

```bash
python setup_routers.py --routers update_failed.txt --preset preset-services-only.txt
```

Флаг `--manual` запрашивает подтверждение перед каждым роутером.

## Генератор списков

Сгенерировать файлы отдельно от настройки роутера:

```bash
python generate_geo_domains.py --preset preset-services-only.txt
```

Использовать уже скачанные базы:

```bash
python generate_geo_domains.py --offline --preset preset-services-only.txt
```

Найти категории по части имени:

```bash
python generate_geo_domains.py --offline --search telegram
```

Только скачать базы:

```bash
python generate_geo_domains.py --pull
```

Генератор создаёт файлы `geosite_domains_*.txt` и `geoip_ips_*.txt` рядом со скриптами. Старые файлы с такими именами перезаписываются.

## Состав проекта

- `install_wireguard.py` — установка и настройка одного роутера;
- `setup_routers.py` — пакетное обновление нескольких роутеров;
- `generate_geo_domains.py` — загрузка баз и генерация списков;
- `.env.example` — шаблон переменных окружения для доступа к роутеру;
- `preset-services-only.txt`, `preset-ru-direct.txt` — примеры пресетов.


## Веб-интерфейс

Локальная веб-панель предоставляет те же основные операции, что и CLI: установку
WireGuard, обновление списков, смену endpoint, пакетную обработку роутеров,
редактор пресетов, поиск категорий и журнал задач.

Установка для Windows:

```powershell
.\install_web.ps1
```

Скрипт создаст изолированное окружение `.venv`, установит зависимости и добавит
на рабочий стол ярлык «Netcraze WireGuard». Ручной запуск:

```powershell
.\run_web.ps1
```

По умолчанию панель открывается на `http://127.0.0.1:8765` без авторизации.
В разделе «Настройки» сохраните общие учётные данные роутеров. Они шифруются
ключом из локального каталога `.webdata` и не передаются в браузер.

На странице «Роутеры» можно импортировать текстовый файл. В каждой строке укажите
адрес и, через пробел, необязательное название: `192.168.1.1 Дом`. Пустые строки
и комментарии с `#` игнорируются.

Для доступа с других устройств локальной сети:

```powershell
$env:NETCRAZE_WEB_HOST = "0.0.0.0"
.\run_web.ps1
```

В этом режиме используйте HTTPS reverse proxy и задайте
`NETCRAZE_SECURE_COOKIE=1`. Не публикуйте панель напрямую в интернет.

> [!CAUTION]
> Веб-операции `install` и `update`, как и CLI, удаляют все существующие
> списки и правила DNS-маршрутизации перед созданием новых. Интерфейс требует
> явного подтверждения перед постановкой такой задачи в очередь.

Для завершившейся с ошибками задачи можно отметить только нужные роутеры и
запустить от 1 до 20 повторных прогонов. По умолчанию выполняется один прогон;
каждый прогон последовательно обрабатывает все отмеченные роутеры.
Для прерванной или отменённой задачи можно начать новый проход по любым выбранным роутерам
исходной задачи. Статусы целей и тексты ошибок обновляются на странице задачи
через SSE без полной перезагрузки страницы.
